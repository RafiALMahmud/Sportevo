# SportEvo logo

The original artwork was supplied and selected by the site owner as `Dynamic Green Sports Monogram.png`. `sportevo-logo-original.png` preserves that source file. This is the owner's artwork, not the alternative logo generated during concept exploration.

`sportevo-logo.webp` is a 360 × 240 optimized copy with the full composition, colors and background retained. It is shared by the navigation, footer and authentication pages. `favicon.png` and `apple-touch-icon.png` fit the original composition into square black canvases for browser icons. No generated replacement or background removal was applied.

The owner subsequently requested background removal. The built-in image generation tool produced `sportevo-logo-transparent.png` using the original image as the edit target. The active assets are now `sportevo-logo-transparent.webp`, `favicon-transparent.png` and `apple-touch-icon-transparent.png`; their alpha channels are preserved, and the logo component has no background fill. Previous opaque versions remain available alongside the original.

Background removal prompt: "Remove only the black rectangular backdrop and diffuse background haze from the owner's selected SportEvo logo. Preserve the S/E composition, football, tennis ball and net, athlete, court panels, green/mint/coral/white colors and fine lines. Keep filled green panels, remove the backdrop in open negative spaces, use clean edges without black fringes, and export actual alpha transparency. No redesign, new symbols, text or cropped artwork."
